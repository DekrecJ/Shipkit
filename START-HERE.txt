SHIPKIT v0.1.0 — QUICK START
============================

REQUIREMENTS
- Python 3.10+
- Git
- Codex installed

WINDOWS
1. Clone the repository:

   git clone https://github.com/DekrecJ/Shipkit.git
   cd Shipkit

2. Run:

   Set-ExecutionPolicy -Scope Process Bypass
   .\install-codex.ps1

3. Restart Codex.

LINUX / macOS

   git clone https://github.com/DekrecJ/Shipkit.git
   cd Shipkit
   chmod +x install-codex.sh
   ./install-codex.sh

Then restart Codex.

AUTOMATIC ACTIVATION TEST
Open an empty project folder in Codex and write:

   I want to create a SaaS for repair shops where mechanics update
   repairs and customers can track their vehicles.

Expected start:

   ◆ ShipKit active

MANUAL / FORCED ACTIVATION

   $shipkit-router Build a SaaS for repair shops...

VERIFY FROM TERMINAL

   shipkit doctor
   shipkit --version

Windows fallback if shipkit is not on PATH:

   py -3 -m shipkit doctor
   py -3 -m shipkit --version

MAIN COMMANDS

   shipkit init
   shipkit status
   shipkit task TASK-001 --status in_progress
   shipkit task TASK-001 --status completed
   shipkit check

UNINSTALL CODEX INTEGRATION

   shipkit uninstall codex

Then optionally remove the Python package:

   python -m pip uninstall shipkit-ai
